# Running the analysis

Run commands from the root of the cloned or extracted repository after `python -m pip install -e .`. Keep the checkout: the orchestration scripts and plot configuration live alongside the Python package.

## Fiducial analysis

The command below reconstructs Chen and Carrón FANS, computes the projected statistics and multiplicity controls, and then performs the fiducial preferred-axis analysis:

```bash
python scripts/run_referee_revision.py fiducial \
  --data-dir data --sconce-fits data/nodes_scms.fits \
  --outroot results/fiducial --stage all --n-jobs 8 \
  --bootstrap-B 1000 --null-B 1000
```

The run directory is:

```text
results/fiducial/v88_fiducial_z010_z060_L10_N3_R10_A35/
```

Use `--stage projected` to run the projected part and multiplicity controls first. Add the axis analysis later with the same command and `--stage extrinsic`, preserving the code, input paths, seed, bootstrap settings, and NSIDE settings. The launcher checks compatibility with the completed projected stage.

The fiducial geometry uses three 10 h⁻¹ Mpc segments per arm, a 10 h⁻¹ Mpc linking radius, a 35-degree half-opening angle, a 70 h⁻¹ Mpc edge margin, and a 5 h⁻¹ Mpc knot-clustering length. Accepted systems have at least two valid arms. All observed multiplicities are included in the full sample; classes are also analysed separately. The composition-standardised control uses two- and three-arm systems and reports unavailable results when support is insufficient.

## Robustness grid

After the fiducial run, use:

```bash
python scripts/run_referee_revision.py grid \
  --data-dir data --sconce-fits data/nodes_scms.fits \
  --outroot results/grid27 --stage projected --n-jobs 8 \
  --bootstrap-B 1000 --null-B 1000 \
  --fiducial-run results/fiducial/v88_fiducial_z010_z060_L10_N3_R10_A35
```

The 27 configurations vary segment length (7.5, 10, 12.5 h⁻¹ Mpc), linking radius (8, 10, 12 h⁻¹ Mpc), and half-opening angle (30, 35, 40 degrees). The grid is projected only; the launcher rejects an extrinsic grid request.

## Outputs

| Location relative to a run | Contents |
|---|---|
| `referee_multiplicity/chen/`, `referee_multiplicity/carron/` | Multiplicity statistics, fractions, composition controls, paired bootstrap arrays, and integrity reports. |
| `paper_tables/` | Combined count, multiplicity, and trend tables. |
| `revision_manifest.json`, `revision_commands.log` | Parameters, input metadata, dependency versions, source signature, and commands. |
| `fans_fits/` | FITS exports generated by the pipeline. |

The grid root also receives `grid_summary/`. The common final collection defaults to `results/paper_final_plots_and_tables/`; set `--paper-outdir` to choose another destination. Publication panels show the full sample and the main two-/three-arm classes.

Check `sample_integrity.json` for each catalogue and the support indicators in the multiplicity tables before interpreting results. Raw diagnostic arm files may include arms from rejected parents; use the accepted analysis products.

The [FITS data model](FITS_DATA_MODEL.md) and [statistical methods](REVISION_METHODS.md) provide further details.

## Useful options

- `--dry-run`: prints commands without processing inputs or creating output directories.
- `--n-jobs N`: sets available workers; the launcher splits work between the two catalogues.
- `--galleries`: also writes individual FANS galleries for the fiducial run.
- `--skip-paper-products`: defers the final plot collection.
- `--hash-inputs`: records content hashes instead of relying only on input metadata.
- `--resume`: reuses a completed projected stage only when its code, inputs, and statistical settings match. Use a new output root for this cleaned distribution if the old run's source signature differs.

## Statistical settings

The default is **1000 bootstrap resamples**, matching the author's confirmed final paper configuration. The recommended launcher also uses **1000 block sign-flip nulls**, HEALPix `NSIDE=16`, and a fiducial axis scan with `NSIDE=32`. Direct multiplicity and extrinsic commands use the same 1000-bootstrap default. Explicit overrides, including zero to disable a bootstrap stage, remain available.

Auxiliary node geometry and Carrón shell matching use Astropy **Planck18**, recalculating distances from the original shell redshift boundaries. Use a new output directory when switching from the earlier distribution: bootstrap counts and cosmological geometry are scientific run settings.

`configs/fiducial.yaml` documents the settings; the launcher does not parse it as a runtime configuration file.

## Tests

```bash
python -m pip install -e ".[dev]"
python -m pytest -q
```

The tests use synthetic examples and do not replace validation against the original survey inputs. The optional `legacy-plots` extra is needed only when an old plot collection requires reading text from a legacy PDF.
